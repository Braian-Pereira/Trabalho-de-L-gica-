Dupla: Braian e Kael

---------------------------------------------------------

1. CONTEXTO DO PROJETO

---------------------------------------------------------

Este projeto e o Projeto Avaliativo desenvolvido para a disciplina de Logica para Ciencias da Computacao. O objetivo e desenvolver um sistema utilizando a linguagem Prolog capaz de representar conhecimentos e responder a consultas com base em fatos e regras logicas.

O tema escolhido foi o "Sistema de indicacao de animais para adocao", que visa recomendar animais conforme o espaco disponivel, o perfil e as caracteristicas do interessado.
